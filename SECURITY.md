# Security policy

## Supported versions

Only the [latest release](https://github.com/fa-saikat/retropie-rom-manager/releases/latest) gets security fixes. Fixes ship as a new patch release.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through GitHub instead: on the repository's **Security** tab, choose **Report a vulnerability**, or go straight to the [new advisory form](https://github.com/fa-saikat/retropie-rom-manager/security/advisories/new).

Include what you found, how to reproduce it, and which version you tested. You should get a reply within a week. Once a fix is released, the advisory is published with credit to you, unless you'd rather stay anonymous.

Things that are in scope include extracting archives outside the ROM folder, running unexpected commands through the install, scrape or play actions, and problems with how the app asks for elevated privileges when installing Skyscraper.
