# Fonts

Both families are embedded in the app binary (see `src/assets.rs`), so the
UI looks the same on every machine. Both are under the SIL Open Font License
1.1; the licence texts are alongside.

| Family | Use | Source |
|---|---|---|
| Inter 4.1 (Regular, Medium, SemiBold, Bold) | All interface text | https://github.com/rsms/inter, `Inter-OFL.txt` |
| Poppins (Regular, Medium, SemiBold, Bold) | Detail text: key hints, file names, extensions | https://github.com/google/fonts/tree/main/ofl/poppins, `Poppins-OFL.txt` |
